ARUNODAYA KUNDLI ADD-ON — केवल नई फाइलें
========================================

इस ZIP में केवल ये नई फाइलें हैं:
- kundli-dosha.js
- kundli-report.js
- kundli-pdf.js
- kundli-pdf.css

मौजूदा main.js, kundli.js, panchak-engine.js, style.css और package.json इस ZIP में शामिल नहीं हैं और बदले नहीं गए हैं।

इन्हें अपनी रिपॉज़िटरी की src/ डायरेक्टरी में अलग-अलग जोड़ें।

महत्वपूर्ण तकनीकी सीमा:
आपकी मौजूदा buildKundli(input) HTML string लौटाती है, structured ग्रह-डेटा नहीं। इन नए मॉड्यूल से वास्तविक रिपोर्ट बनाने के लिए मौजूदा कुंडली गणना से structured डेटा उपलब्ध कराना और छोटा integration बदलाव करना जरूरी होगा। सही डेटा का आकार:

{
  name: "नाम",
  date: "YYYY-MM-DD",
  time: "HH:MM",
  place: "जन्म स्थान",
  ascendantLongitude: 123.45,
  planets: [
    { short: "मं", full: "मंगल", longitude: 222.2, retrograde: false },
    { short: "रा", full: "राहु", longitude: 100.1, retrograde: true },
    { short: "के", full: "केतु", longitude: 280.1, retrograde: true }
  ]
}

ये केवल schema का उदाहरण है, किसी व्यक्ति की वास्तविक गणना नहीं। सभी longitude पहले से निरयन/लाहिरी होनी चाहिए।

PDF बनाने के लिए ब्राउज़र Print dialog खुलेगा; वहाँ "Save as PDF" चुनें। कोई नया npm package आवश्यक नहीं है।

सीमा:
मंगल दोष की जाँच में लग्न से 1, 2, 4, 7, 8, 12 भाव का एक सामान्य नियम इस्तेमाल किया गया है। कालसर्प की जाँच एक सरल संकेत है। अलग-अलग परंपराओं में नियम/अपवाद अलग हो सकते हैं। मौजूदा दशा, नवांश और अयनांश गणना का स्वतंत्र सत्यापन भी बाकी है।

इन फाइलों को जोड़ना मात्र वेबसाइट पर सुविधा सक्रिय नहीं करेगा; integration बदलाव अलग से आवश्यक है। आपने कहा था कि मौजूदा फाइलें शामिल न की जाएँ, इसलिए ZIP में केवल add-on फाइलें रखी गई हैं।
