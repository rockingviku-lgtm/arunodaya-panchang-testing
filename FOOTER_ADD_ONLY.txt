महत्वपूर्ण:
- ZIP के सात HTML पेज repository की उसी public root directory में रखें जहाँ index.html है।
- ये पेज एक-दूसरे से लिंक हैं और हर पेज से मुख्य वेबसाइट पर वापस जाने का लिंक भी है।
- main.js में पुराने code को delete या replace न करें; ऊपर बताए गए snippets ही जोड़ें।
- Gmail संपर्क फ़ॉर्म केवल Gmail compose window खोलता है; संदेश अपने-आप नहीं भेजता।
- AdSense के लिए यह लिखित नीति-पाठ है, Google की consent/CMP और privacy requirements लागू होने पर अलग से सही तरह configure करनी होंगी।
